ℹ️ Шпаргалка

.mcaddon — двойной клик по файлу, Minecraft импортирует сам.
Датапак/карта — в папку datapacks мира, затем /reload.
Плагин — исходники, собери через mvn package (BUILD.txt внутри).
Мод Fabric — шаблон gradle на fabricmc.net/develop.

Файл всегда дублируется в чат с ботом — не потеряешь.
